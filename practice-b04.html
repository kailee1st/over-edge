B-04 실습 — 새로고침에도 남는 목록

브라우저 localStorage 에 저장합니다. 추가·삭제한 뒤 새로고침해도 그대로 남습니다. 서버로는 아무것도 보내지 않습니다.

⚠

실습용 가짜 데이터만 넣어 주세요. 실제 이름·이메일·전화번호·병원명을 넣지 마세요. 이 페이지의 값은 그대로 개발자 도구에 보입니다. 아래 「예시 데이터 채우기」를 쓰시면 안전합니다.

—

지금 localStorage 에 저장된 내용

개발자 도구 → Application → Local Storage 에서 보이는 것과 같은 값입니다.

—

localStorage 는 주소(origin)별·브라우저별 저장소입니다. localhost 에서 넣은 값은 배포 주소에서 보이지 않고, 그 반대도 마찬가지입니다. 정상 동작입니다.
