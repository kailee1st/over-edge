# Dr.Hand Design System v1

> 브랜드 한 줄: **신뢰의 골격에 온기를 입힌다.** 공통 뿌리 — "집안에 의사 한 명".
> 원천 문서: 브랜드_가이드라인_v1.md · 화면정의서_v1.md (Overedge/과제/knowledge)

## 컬러 사용 규칙
- 비율: 틸+뉴트럴 ≈85% / 웜 ≈10% / OK 그린 ≈5%
- Primary = #128B96 (틸). CTA·링크·로고. 그라디언트는 135deg #128B96→#16A2AF
- 웜(#C96F4A)은 감정을 받는 문장·손 심볼에만 — 버튼·경고·에러 금지
- OK 그린(#37C46A)은 근거 있는 안심 문장("~라고 하셨어요" 형식)에만
- 수치·데이터 화면(시장·BM·지표)은 틸+뉴트럴만

## 타이포
- Pretendard 단일 서체. H1 30-32/800, H2 19-22/800, 본문 14.5-15/400/행간 1.65, 캡션 12-13/500
- 의료 용어는 괄호 눈높이 풀이 병기: "고지혈증(피에 기름이 많은 상태)"

## 보이스 4원칙
1. 사실 → 풀이 → 다음 한 걸음 (결론 없는 문장 금지)
2. 감정을 먼저 한 문장으로 받는다 (두 문장부터 신파)
3. 괜찮은 것은 괜찮다고 말한다 — 반드시 근거와 함께, "~라고 하셨어요" 전달 형식으로
4. "진단이 아닌 정리" 고지를 자연스러운 문장으로 (공식: "진단은 병원에서. 이해는 Dr.Hand가 함께합니다.")

## 금지
- 의사 대체 단정("그 한 명이 될게요") · 진단/처방/효능 보장/근거 없는 안심
- "안 쓰면 불효" 프레임 · 질병 공포 · 가짜 긴급성/타이머
- 청진기 심볼 단독 사용 · 슬로건 문구 변형 (공식 저장소: 시장조사_카드팩 카드 4)
